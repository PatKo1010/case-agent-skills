# Case record schema

All JSONL records require `id`, `kind`, `attributes`, `source_pages`, `source_quote`, `confidence`, and `verification`.

Do not merge contradictory records. Link them with `conflicts_with`.


`verification` is `unverified` or `visual`; provisional indexes retain the source status. `source_quote` is a nonempty verbatim substring of a cited OCR page. IDs must be unique across the four JSONL files. Confidence is a finite number between 0 and 1. Include at least one document record; the other arrays may be empty when the source supports no records of that kind.

`index_manifest.json` is generated by the validator, not the model. It contains `schema_version`, `ocr_fingerprint`, `source_sha256`, and SHA-256 hashes for all five output files. OCR content or verification changes invalidate its binding.
