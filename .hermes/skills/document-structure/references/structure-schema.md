# Lightweight document structure schema

This layer represents document organization, not case meaning.

## pages.jsonl

Each row contains:
- `page`: physical 1-based page number
- `document_id`: inferred containing document
- `title`: best structural title for the page, if detected
- `block_ids`: ordered block IDs
- `source_verification`: `unverified` or `visual`

## documents.jsonl

Each row contains:
- `id`
- `title`
- `start_page`
- `end_page`
- `boundary_confidence` (0..1)
- `boundary_rule`
- `source_pages`

Document boundaries are heuristics. Low confidence must remain visible downstream.

## blocks.jsonl

Each row contains:
- `id`
- `document_id`
- `page`
- `source_block_index`
- `type`: one of `title`, `narrative`, `table`, `qa`
- `text`: verbatim text from the normalized ingest page
- `bbox`: source bbox when available
- `confidence` (0..1)
- `verification`
- `classification_rule`

The block text must remain source-grounded. This layer may classify layout/role but must not paraphrase the source.

## structure_manifest.json

Generated by the builder/validator and contains:
- `schema_version`
- `ocr_fingerprint`
- `source_sha256`
- SHA-256 hashes for the three JSONL files

Any ingest text, verification or source change invalidates the structure.
